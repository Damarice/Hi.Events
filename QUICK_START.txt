================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: Login fails
  → Check email/password are correct
  → Verify account exists
  → Check browser console for errors

Problem: Registration fails
  → Email may already exist
  → Password must be 8+ characters
  → Check browser console for validation errors

Problem: Cannot reach API
  → Verify internet connection
  → Check if service is online (Render dashboard)
  → May be cold-starting (first request takes longer)

Problem: Page won't load
  → Wait 30 seconds (service may be starting)
  → Refresh page (Ctrl+R)
  → Check browser console (F12)

Problem: Email verification not working
  → Check email spam folder
  → Look in Render logs for verification link
  → May need to manually verify account

For help: Check CLIENT_SETUP_COMPLETE.md or TESTING_GUIDE.md
